
# Power BI Dashboard Files

This folder contains interactive Power BI dashboard projects developed through guided laboratory work, analytics assignments, and applied visualization projects.

The dashboards cover:
- KPI reporting
- DAX calculations and measures
- Sales analytics
- Time-series analysis
- Data visualization
- Customer and product intelligence
- R-integrated analytics workflows
- Forecasting and trend analysis

The final ESE dashboard project represents the culmination of concepts learned throughout the laboratory sessions and integrates multiple analytical and visualization techniques into a comprehensive reporting solution on a curated dataset about different kinds of crime over the years

# Power BI Dashboard Portfolio

This repository contains a collection of Power BI dashboards, analytical reports, and visualization projects developed through structured laboratory coursework, guided analytics exercises, and applied end-semester projects.

The portfolio demonstrates practical experience in:
- Interactive dashboard development
- KPI reporting and business intelligence workflows
- Data cleaning and preprocessing using Power Query
- DAX queries, calculated columns, and measures
- Data modeling and relationship verification
- Trend analysis and forecasting
- Sales, customer, and product analytics
- Power BI integration with R programming for advanced analytics and machine learning visualization

---

## Repository Structure

### `dashboards/`
Contains Power BI `.pbix` dashboard files covering:
- Sales analytics

- Forecasting and visualization workflows

### `docs/`
Contains detailed analytical reports and technical documentation including:
- Dashboard explanations
- Data preprocessing workflows
- DAX query implementations
- Relationship modeling analysis
- Random Forest R analytics reports

### `screenshots/`
Contains dashboard preview images and visualization snapshots for quick project overview.
